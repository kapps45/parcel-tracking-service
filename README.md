# 📦 Parcel Tracker

Консольное приложение на **Go** для управления данными о посылках с использованием **SQLite**.

Приложение позволяет создавать записи о посылках, получать информацию о доставках и изменять их основные параметры. Работа с данными выполняется через SQL-запросы к локальной базе SQLite.

## ✨ Возможности

- 📦 Регистрация новых посылок
- 👤 Получение посылок конкретного клиента
- 🚚 Изменение статуса доставки
- 📍 Изменение адреса получателя
- 🗑️ Удаление записи о посылке
- 🗃️ Хранение данных в SQLite
- 🔢 Автоматическое создание идентификатора посылки

## 📦 Статусы доставки

| Статус | Описание |
|---|---|
| `registered` | Посылка зарегистрирована |
| `sent` | Посылка передана в доставку |
| `delivered` | Посылка доставлена |

## 🗃️ Модель данных

Основная информация хранится в таблице `parcel`.

| Поле | Назначение |
|---|---|
| `number` | Уникальный номер посылки |
| `client` | Идентификатор клиента |
| `status` | Текущий статус доставки |
| `address` | Адрес доставки |
| `created_at` | Дата и время создания записи |

## 🧩 Основные компоненты

| Файл | Назначение |
|---|---|
| `main.go` | Точка входа и запуск приложения |
| `parcel.go` | Работа с моделью посылки и операциями с БД |
| `parcel_test.go` | Автоматизированные тесты операций с посылками |
| `tracker.db` | Локальная база данных SQLite |
| `go.mod` | Описание Go-модуля и зависимостей |
| `go.sum` | Контрольные суммы зависимостей |

## 🧪 Тестирование

Для проверки работы приложения предусмотрен набор тестов для основных операций с данными.

Проверяется корректность:

- 📦 Создания посылок
- 👤 Получения записей клиента
- 🚚 Изменения статуса
- 📍 Изменения адреса
- 🗑️ Удаления посылок
- 🗃️ Работы с данными SQLite

Запустить тесты можно командой:

    go test ./...

Для подробного вывода:

    go test -v ./...

## 🛠️ Используемые технологии

- **Go**

## 🚀 Запуск

Для запуска приложения выполните:

    go run main.go

Перед первым запуском убедитесь, что необходимые зависимости Go установлены.

## 🎯 Цель проекта

Проект предназначен для практики работы с реляционными базами данных в **Go**: подключение SQLite через `database/sql`, выполнение SQL-запросов, управление записями и тестирование операций с базой данных.
